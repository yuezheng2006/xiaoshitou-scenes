## 禁止

- 窄长脸、V 字下巴、幼态脸、过度显老、明显眼袋或疲态；禁止过深法令纹、重眼角纹和过熟叔感。
- 粗黑框、丢眼镜、卷发、夸张后退发际线。
- 普通 175cm 矮壮比例、矮宽压扁、纤细白领体型或夸张肌肉；头大、人物缩小、腿部被压短、腰腹松垮、胯部过低、上下半身 1:1、腿部超过 60% 造成怪物比例、躯干过厚或 5:5 身体分割均不合格。
- 短裤过短露出大段大腿、紧身短裤、贴腿短裤、裤腿卡在膝盖以上过多或变成长裤均不合格。
- 小腿过细、竹竿腿、粗短柱状腿或健美腿均不合格。
- 鞋款漂移成帆布鞋、正装鞋、厚重篮球鞋、现代高帮鞋或 Nike 鞋型；默认只在 New Balance 1906R / 2002R 间选择，必须保留 New Balance 的大写 N 标识，禁止 Nike swoosh。
- 手绘人物采用有细节的扁平 2D 角色插画：保留真人骨相、五官比例和自然不对称，使用清晰且有粗细变化的线稿、平涂色块、局部轻阴影、发丝分组和衣物褶皱表达细节；禁止 3D 玩偶、过度卡通化、照片级写实、磨皮滤镜、玻璃皮肤、网红美颜和过度对称；实物人物也不能退化成泛化 Q 版。
- 单人任务未经请求加入小石头、品牌标识或其他角色。
