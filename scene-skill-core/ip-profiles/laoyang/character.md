# 老杨 · Character Lock

## 身份锚点

- 成熟中国男性，约 35 岁方向；成熟但不过熟，不能显老。
- 180cm / 86kg，高大结实但不能横向压扁，肩宽适中，腿明显较长，上短下长约 4:6；头身约 1:7.5，躯干约占站立高度 40%，腿约占 60%，必须呈现高挑视觉档。
- 长但不细的长方椭圆脸，圆下巴，浅灰细框大镜片眼镜。
- 自然短直发约 3-5cm；肤色健康小麦；下唇明显、侧颊与下颌线只有极淡短胡茬。
- 常穿 New Balance 1906R 或 2002R 复古跑鞋（以用户提供的两张鞋图为参考）；单人和同批任务中鞋款保持一致。
- 手绘模式使用扁平黑线；实物模式使用成熟克制的风格化 3D。

## 模式差异

- physical：以用户当前会话提供的真实人脸作为私有校准，保留黑色短碎发、较厚深色方框眼镜、宽方圆脸和轻微全脸胡茬。
- handdrawn / knowledge-card：继续使用已验收的风格化人脸参考，不把 physical 真人照片带入公开资产。

## 行为锁

老杨必须通过讲解、指向、批注、检查、递交判断或收束动作推动画面。单人图不能只是头像或站桩肖像；双 IP 图中老杨负责主讲/调度，小石头负责执行。

## 禁止

- 窄长脸、V 字下巴、幼态脸、过度显老、明显眼袋或疲态。
- 粗黑框、丢眼镜、卷发、夸张后退发际线。
- 普通 175cm 矮壮比例、矮宽压扁、纤细白领体型或夸张肌肉；头大、人物缩小、腿部被压短、躯干过厚或 5:5 身体分割均不合格。
- 鞋款漂移成帆布鞋、正装鞋、厚重篮球鞋、现代高帮鞋或 Nike 鞋型；默认只在 New Balance 1906R / 2002R 间选择，必须保留 New Balance 的大写 N 标识，禁止 Nike swoosh。
- 手绘人物混入 3D 玩偶语言，或实物人物退化成泛化 Q 版。
- 单人任务未经请求加入小石头、品牌标识或其他角色。
