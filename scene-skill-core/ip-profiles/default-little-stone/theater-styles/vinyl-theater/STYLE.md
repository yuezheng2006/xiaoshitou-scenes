# 潮玩小剧场 · 视觉风格原子

## 视觉风格原子

创作一张 **3D 潮玩 / vinyl-toy** 气质的老杨小剧场插图。哑光材质、柔光、干净描边、收藏级手办感。

这不是照片、不是半写实厚涂、不是路径 B 白底黑线课堂手绘。

## 身份与 Likeness Policy

- 身份只来自 **APPROVED** `author-persona-theater-expression-sheet.png` + `author-persona-theater-face-lock.png`（+ 服/体 sheet）。
- **神似**：保留可识别锚点——面颊有肉的软圆方脸、粗黑软方框眼镜、短硬上冲黑发、眉粗、下唇不薄、淡茬、~36–40、藏蓝 T。
- **禁止照片级**：不要毛孔级皮肤、不要自拍滤镜、不要宣称 biometric 1:1。
- **禁止**向生图传入真人自拍（会话校准仅本地，不进公开 prompt）。

## 服装硬锁（Hero outfit）

藏蓝 crew 短袖 T + 宽松卡其 Bermuda（微微过膝）+ 浅色短休闲袜 + New Balance **2002R** + 左手黑色运动表。  
跨图只改姿态/表情/场域，不换装。

## 渲染基因

- 哑光 vinyl / collectible matte
- 柔和漫射光，阴影干净
- 轻微清晰描边 OK；禁止写实皮肤散射追真
- 背景：干净柔光底或轻度场域道具；忌证件照海报、忌办公室写实堆砌

## 负向（风格层）

- 照片级 / 半写实插画 / 厚涂写实
- 路径 B 米色教学服 + 扁平黑线白板
- 韩范磨皮 V 脸、幼态娃娃脸、削尖下颌
- 细丝金圆框眼镜、软卷对称齐刘海、buzz 寸头
- 脸贴图矩形白雾、双领口接缝
